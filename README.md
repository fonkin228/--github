# Распределение пополнений — Telegram Mini App + бот

Калькулятор распределения пополнений на три части с округлением вверх.
Работает тремя способами: автономным HTML-файлом без сервера, как Mini App внутри
Telegram и как обычный бот. Результат выгружается в «живой» xlsx с формулами.

**Как считает**

Сумма собирается из отдельных пополнений (кнопка «+»), по каждому можно отметить
удержанную комиссию. Дальше пять пронумерованных этапов с объяснением, что
происходит на каждом: Пополнения → Доля 1 → Налог → Заработок → Резюме.

Пакетный расчёт списком остался только в боте (пришлите несколько сумм, каждую
с новой строки) — в интерфейсе такой вкладки нет.

**Вкладки**

- **Этапы** — сам расчёт.
- **Аналитика** — сводка по неделям и месяцам: пополнения, налог, заработок, остаток.
  Даты берутся с самих пополнений; если в расчёте пополнения разных дат, налог и
  заработок делятся между ними пропорционально суммам.
- **Параметры** — проценты, шаг округления, ставка комиссии, база для заработка.
- **История** — сохранённые расчёты и «База в Excel»: вся история выгружается одним
  xlsx, файл можно править руками и загружать обратно.

Тема оформления переключается в правом верхнем углу: авто / светлая / тёмная.

👉 Пошаговый план запуска и что нужно сделать со своей стороны — в [PLAN.md](./PLAN.md).

## Быстрый старт

```bash
npm install
cp .env.example .env          # BOT_TOKEN и WEBAPP_URL
npm run build                 # сборка Mini App (клиент + сервер)
npm run build:standalone      # автономный HTML-файл: web/dist-standalone/index.html
npm start                     # сервер + бот, http://localhost:3000
```

Разработка с горячей перезагрузкой (два процесса):

```bash
npm run dev:server            # API на :3000
npm run dev:web               # Vite на :5173, проксирует /api на :3000
```

Открыть `http://localhost:5173` в обычном браузере можно без Telegram — при
`ALLOW_DEV_AUTH=true` сервер подставляет фиктивного пользователя (id = 0).
**В проде обязательно `ALLOW_DEV_AUTH=false`.**

```bash
npm test                      # 27 юнит-тестов
npm run typecheck             # tsc по обоим пакетам
```

```
  src/db.ts        SQLite: пользователи, параметры, история

```

## API

Все запросы, кроме `/api/health`, требуют заголовок `X-Telegram-Init-Data`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | статус сервера, настроен ли бот |
| GET | `/api/me` | пользователь + его сохранённые параметры |
| POST | `/api/calc` | расчёт `{inputs[] \| text, params?, save?}` |
| GET / PUT | `/api/settings` | получить / сохранить параметры |
| POST | `/api/export` | скачать xlsx (бинарный ответ) |
| POST | `/api/export/telegram` | попросить бота прислать файл в чат |
| GET | `/api/history` | список расчётов |
| GET / DELETE | `/api/history/:id` | открыть / удалить расчёт |
| DELETE | `/api/history` | очистить историю |

## Логика расчёта

При `Params { p1: 0.89, p2: 0.07, p3: 0.04, step: 1000, commissionRate: 0.01, p3Base: 'nMinusRoundUp' }`:

```
Этап 1: N = Σ(пополнение);  C = Σ(комиссия по отмеченным)
raw1   = N × p1                       → C   629 181,05
part1  = CEILING(raw1, step)          → D   630 000,00
roundUp= part1 − raw1                 → E       818,95
part2  = N × p2                       → F    49 486,15
base3  = N − roundUp                  →     706 126,05
base3  = N − roundUp − C
part3  = base3 × p3                   → G  «Заработок»
total  = part1 + part2 + part3        → H   707 731,19
diff   = total − N                    → I       786,19
```

Комиссия уменьшает только базу «Заработка»: доля 1 и налог считаются от полной суммы пополнений.

`p3Base` задаёт базу для третьей доли:

| Значение | База | Когда применять |
|---|---|---|
| `nMinusRoundUp` | `N − roundUp` | по умолчанию — рабочая формула |
| `n` | `N` | если добавку округления вычитать не нужно |
| `part1` | `part1` | так считала первая версия таблицы (даёт недобор ≈0,44%) |

Поскольку 89 + 7 + 4 = 100%, при нулевой добавке округления три части складываются
ровно в N. Добавка вверх даёт небольшой положительный остаток: `Δ = 0,96 × roundUp`.

## Команды бота

- `/start` — кнопка открытия Mini App
- `/params` — текущие проценты и шаг округления
- `/help` — справка
- просто прислать сумму (или несколько, каждую с новой строки) — бот посчитает и предложит файл

## Переменные окружения

См. `.env.example`. Ключевое: `BOT_TOKEN`, `WEBAPP_URL` (публичный https),
`ALLOW_DEV_AUTH` (false в проде), `BOT_MODE` (`polling` / `webhook` / `off`).
