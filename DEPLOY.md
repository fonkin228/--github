# Деплой: чтобы бот и общая база работали круглосуточно

Автономный файл (`Калькулятор.html`) и статический хостинг решают одну задачу —
персональный расчёт. Как только появились **общая база и уведомления в группу**,
нужен постоянно работающий сервер: он хранит базу, отвечает боту и пишет в чат.

---

## Что где живёт

| Что | Где | Нужен сервер? |
|---|---|---|
| Расчёт по этапам | в браузере | нет |
| Выгрузка xlsx | в браузере | нет |
| Общая история и аналитика на всех | на сервере | **да** |
| Бот, уведомления, `/baza` | на сервере | **да** |

Важно: приложение должно открываться **с адреса сервера**, а не с GitHub Pages.
Иначе оно будет работать в автономном режиме и общей базы не увидит.

---

## Вариант 1. Render — бесплатно, для начала

1. Залить проект в репозиторий GitHub (можно тот же, что уже есть — положить туда всю папку `tg-split-calc`).
2. [render.com](https://render.com) → **New** → **Web Service** → подключить репозиторий.
3. Настройки:
   - **Runtime**: Node
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. В разделе **Environment** добавить переменные:

```
BOT_TOKEN       = токен от @BotFather
BOT_MODE        = webhook
WEBHOOK_SECRET  = любая случайная строка
NODE_ENV        = production
ALLOW_DEV_AUTH  = false
WEBAPP_URL      = https://ваш-сервис.onrender.com
PUBLIC_URL      = https://ваш-сервис.onrender.com
MINIAPP_LINK    = https://t.me/имя_бота/короткое_имя_приложения
```

Адрес сервиса Render показывает после первого деплоя — впишите его в две
переменные и передеплойте.

5. В @BotFather: `/setmenubutton` и `/editapp` → указать тот же `WEBAPP_URL`.

**Минусы бесплатного тарифа Render, о которых честно стоит знать:**

- Сервис засыпает после 15 минут без запросов. Первое обращение будит его — это
  занимает до минуты. Именно поэтому `BOT_MODE=webhook`, а не `polling`:
  входящее сообщение разбудит сервер само.
- **Диск не сохраняется между перезапусками.** База лежит в файле `data/app.db`,
  и при передеплое или пробуждении она может обнулиться. Страховка встроена:
  при каждом импорте бот присылает в группу актуальный файл базы — его всегда
  можно загрузить обратно. Но если база важна, берите второй вариант.

## Вариант 2. Railway — с постоянным диском

Дороже (около 5 $ в месяц после стартового кредита), зато база не теряется.

1. [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
2. **Variables** — те же, что выше, но `BOT_MODE=polling` (сервис не засыпает,
   вебхук не нужен) и добавить `DATABASE_PATH=/data/app.db`.
3. **Settings → Volumes** → создать том и примонтировать в `/data`.
4. Адрес выдаётся в **Settings → Networking → Generate Domain** — его вписать в
   `WEBAPP_URL` и в BotFather.

## Проверка после деплоя

- [ ] `https://ваш-адрес/api/health` отвечает `{"ok":true,"botConfigured":true}`
- [ ] Приложение открывается по этому адресу и **не** показывает плашку dev-режима
- [ ] В личке бот отвечает на `/start`
- [ ] Команда `/baza` присылает файл
- [ ] В группе кнопка «Открыть калькулятор» работает
- [ ] Импорт базы в приложении → в группу приходит уведомление и свежий файл

## Кто имеет доступ к базе

База общая, поэтому вход в неё ограничен: сервер пускает только тех, кто состоит
в группе, куда добавлен бот. Проверка идёт при каждом запросе через Telegram
(результат кэшируется на 5 минут), вести списки руками не нужно — добавили
человека в группу, у него появился доступ; убрали — пропал.

Дополнительно можно задать в переменных окружения:

```
OWNER_ID       = ваш Telegram ID — доступ есть всегда
ALLOWED_USERS  = 111,222 — доступ вне группы
```

Пока бот не добавлен ни в одну группу и списки пусты, ограничивать не по чему —
доступ открыт всем, кто нашёл бота. Это видно в `/api/health` по полю
`accessOpen: true`. **Добавьте бота в рабочую группу до того, как дадите ссылку кому-то ещё.**

Отдельно напомню про `ALLOW_DEV_AUTH=false` в проде: с `true` проверка подписи
Telegram отключается и API открыт полностью.

## Бот в группе

Бот в группе намеренно молчаливый: он не читает переписку и не реагирует на числа.
Отключать приватность в `/setprivacy` не нужно — команды он видит всегда.

Что делает:

- по `/start` — даёт кнопку со ссылкой на приложение;
- по `/baza` — присылает текущую базу файлом;
- сам пишет, когда кто-то из участников загрузил новую базу, и прикладывает её.

Ссылка на приложение для групп — это `MINIAPP_LINK` вида `https://t.me/имя_бота/calc`.
Короткое имя (`calc`) задаётся в @BotFather при `/newapp`. Обычные кнопки Web App
внутри групп Telegram не разрешает, поэтому используется именно ссылка.
